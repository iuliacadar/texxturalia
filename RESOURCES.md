## Editor shortcuts & setup (VS Code)

| Shortcut | Action |
|---|---|
| `Ctrl+U` | View page source (browser) |
| `Ctrl+Shift+X` | Extensions panel |
| `Alt+Shift+F` | Format document — keeps the code weave clean |
| `Ctrl+F` | Quick find (e.g. batch-replace `#1c1c1c` → `#2c2c2c`) |
| `Ctrl+Shift+R` | Hard refresh (browser) — bypass cache for `style.css`/`script.js` |
| `F12` → Console | The laboratory: run JS lines against the live page |

Extensions: **Prettier** (formatting), **Auto Rename Tag** (renames the
closing tag automatically).
